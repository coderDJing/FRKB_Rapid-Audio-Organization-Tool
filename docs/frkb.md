# 更名说明

本项目以前叫 **FRKB**，现在产品名是 **Track Studio**，GitHub 仓库是 [Track-Studio](https://github.com/coderDJing/Track-Studio)。

## 对已安装用户

- 可以继续用应用内更新，仍会覆盖原来的安装身份。
- 桌面快捷方式和开始菜单会改成 Track Studio。
- Windows 安装目录和可执行文件仍叫 `FRKB`，这样才能覆盖升级而不是并排再装一份。
- 原有音乐库不用迁移；磁盘上的声明文件仍是 `.frkbdb`。
- 设置仍保存在原来的用户数据目录。
